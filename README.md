# HastaKalaShop

HastaKalaShop is an Android application developed for handicraft sellers and artisans to manage inventory, sales records, and craft collections digitally.

## Features
- User Login and Registration
- Forgot Password Functionality
- Inventory Management
- Sales Management
- Craft Collection Management
- Low Stock Alerts
- Sales Analytics using Pie Chart
- Room Database Integration

## Technologies Used
- Kotlin
- XML
- Android Studio
- Room Database
- MPAndroidChart
- Material Design

## Project Objective
The main objective of this project is to simplify handicraft shop management by providing a digital platform for inventory tracking, sales recording, and analytics.
